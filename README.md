# Solar Irradiance Meter

A portable solar irradiance meter built using Arduino Nano.

## Features

- Voltage measurement
- Current measurement using ACS712
- Lux measurement using BH1750
- Power calculation
- LCD display
- EEPROM calibration

## Components

- Arduino Nano
- ACS712
- BH1750
- TP4056
- XL6009
- LCD 16x2 I2C
- Li-ion Battery
